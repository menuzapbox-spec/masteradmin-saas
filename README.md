# Grazia White Label v2.0 — Supabase

Cardápio/delivery White Label com layout mobile inspirado em apps de delivery, painel Admin, catálogo em tempo real, login protegido, pedidos, dúvidas e imagens.

## Stack
- Vite + React
- Supabase PostgreSQL
- Supabase Auth
- Supabase Storage
- Supabase Realtime
- Render
- GitHub

## Configuração
Consulte `SUPABASE-PASSO-A-PASSO.md` e execute `supabase-schema.sql` no SQL Editor do projeto Supabase.

### Variáveis do Render
```text
VITE_SUPABASE_URL
VITE_SUPABASE_ANON_KEY
```

Nunca coloque a chave `service_role` no frontend.
